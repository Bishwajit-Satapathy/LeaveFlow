# LeaveFlow

LeaveFlow is a Microsoft Power Apps canvas app for employee leave requests and manager approvals.

## Package

The exported Power Apps solution package is named `LeaveFlow_1_0_0_1_managed.zip`. It is a **managed solution package**, intended to be imported into a Power Platform environment rather than run directly from GitHub.

## Import

1. Open the [Power Apps maker portal](https://make.powerapps.com/).
2. Select the target environment.
3. Go to **Solutions** and choose **Import solution**.
4. Select the managed solution ZIP and follow the import wizard.
5. Review any connection references or environment variables and configure them as required.
